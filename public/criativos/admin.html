O que você escrever aqui é o que a clínica vê na página do criativo.

Este criativo é um vídeo hospedado no repositório. Ele continua funcionando — só os novos é que entram por link.
O vídeo deste criativo não existe no acervo.
Quem abrir a página vê um aviso no lugar do player. Converta para link colando a URL do criativo, ou remova a entrada.

Vira player dentro do site: YouTube (vídeo, Shorts ou youtu.be), Instagram (reel ou post), Vimeo, Google Drive (com o link compartilhável), Loom e link direto de arquivo .mp4 / .webm / .mov.
Biblioteca de Anúncios do Meta e TikTok não embutem — entram como botão. Nesses, preencha a Capa para o cartão mostrar uma imagem.

Só precisa quando o link não gera prévia sozinho — aí o cartão mostra esta imagem. Serve qualquer endereço de imagem terminando em .jpg, .png ou .webp.
